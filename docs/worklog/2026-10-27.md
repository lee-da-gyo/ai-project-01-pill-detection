## 추가로 한 일 (저녁) – 전처리 노트북 `02_preprocess.ipynb`

  (범위 밖 1, 엉뚱한 위치 1, 누락 8). 전/후 그림으로 전부 눈으로 검수했다.

  반투명 캡슐(OMACOR)과 파란 알약은 분할이 잘 안 돼서 "박스 안이 비었다"고 잘못 판단한 것이다.
  → "원래 박스와 겹치지 않고 크기가 비슷한 알약일 것"이라는 조건을 더해 1건(진짜 오류)만 남겼다.
  자동 규칙은 반드시 결과를 눈으로 확인해야 한다는 걸 배웠다.
- 박스 보정: 분할 박스와 라벨러 박스의 테두리 차이(중앙값)로 새 박스를 라벨러 기준에 맞췄다.
- 조합 단위 Stratified Group 5-Fold로 나누고 누수가 0인지 `assert`로 확인했다.
  fold마다 val에 train에서 못 본 클래스가 1~7개 있다 (1개 조합에만 있는 클래스 때문).
- YOLO 라벨을 다시 읽어 픽셀로 되돌려 비교했다 (최대 오차 0.001px).
- 기술 메모: Windows에서 `cv2.imread`는 한글 경로를 못 읽어서 PIL로 읽었다.

## 추가로 한 일 – 베이스라인(E0)과 Copy-Paste 증강
- 학습 환경: 로컬 RTX 3060 (12GB)에서 학습한다. Kaggle GPU 주간 한도를 아낄 수 있다.
- 학습·예측·평가·제출 모듈(`train`, `predict`, `evaluate`, `submission`)과 실험 실행 스크립트를 만들었다.
  설정 파일 하나가 실험 하나이고, 명령 한 줄로 학습 → 평가 → 제출 파일 → 실험 기록까지 실행된다. 테스트 14개 통과.
- 1에포크 시험 실행에서 문제 2개를 먼저 잡았다: Windows의 OpenMP 런타임 충돌, 크기 0 박스가 제출 파일에 섞이는 문제.
- **E0 결과** (YOLO11s, 640px, fold 0, 5.7분): val mAP50-95 0.835
  - Ultralytics 평가 0.834와 직접 구현한 COCO 평가 0.835가 일치 → 평가 코드 검증
  - **핵심 발견**: 학습에 있는 약은 AP 0.985, 처음 보는 약 5종은 0.000. 점수 손실의 전부가 "처음 보는 약"이다.
    위치는 모두 맞고, 처음 보는 약을 생김새가 비슷한 아는 약으로 높은 확신(0.9 이상)으로 예측한다.
  - 최종 모델은 전체 데이터로 학습하므로, 실험 비교 지표에 "학습한 약만 mAP"를 추가했다.
  - 가설 "이미지당 상위 4개 제한이 좋을 것" → **기각** (0.835 → 0.822). mAP는 낮은 순위 후보도 점수로 쳐 준다.
- **Copy-Paste 합성 구현**: 알약을 윤곽대로 오려 다른 사진의 빈 자리에 붙인다. 희귀할수록 자주 뽑는다.
  - 문제: 흰 알약은 배경과 색이 비슷해 절반만 오려지는데 라벨은 전체 박스 → 잘못된 라벨이 된다.
  - 해결: "알약은 라벨 박스를 거의 꽉 채운다"는 점을 이용해, 마스크가 박스의 80% 미만만 덮으면 타원 마스크로 대체. 볼록 껍질로 각인 구멍도 채웠다.
  - fold 0 합성 400장 → 클래스별 박스 수 중앙값 9 → 20
- 실험 대기열: E1(해상도 960·1280), E2(YOLO11n·11m·26s), E3(상하 뒤집기·색 증강·Copy-Paste)

## 추가로 한 일 – 5-Fold 교차검증과 최종 모델
- **YOLO11s·11m 5-Fold**: fold 평균 0.853 / 0.855로 차이 없음. fold별 편차가 0.74~0.92로 크다.
- **OOF가 0.62로 낮게 나온 원인 분석**: 56종 중 19종이 한 fold에만 있어, 검증될 때마다 학습에 없는 약이 된다 → OOF 상한 0.661.
  fold별 "처음 보는 약" 수(1·3·3·5·7종)와 점수 순위가 정확히 반대라는 것도 확인했다.
  → 모델 비교는 같은 조건으로 잴 수 있는 **37종 OOF**로 하기로 함: 11s 0.941, 11m 0.936.
    (희귀 19종을 뺀 조건부 비교값이라 56종 Kaggle 점수의 추정치는 아니다)
- **앙상블 설정을 OOF에서 선택**: 11s + 11m WBF가 0.954(+0.013), 1:1 · IoU 0.7.
  다만 같은 OOF에서 12개 중 최댓값을 고른 값이라 낙관적일 수 있다 → 다음 날 메타 검증으로 확인 (10/28 일지).
- **최종 모델**: 232장 전체로 11s 50 에포크 · 11m 83 에포크 학습 (fold별 best epoch 중앙값을 쓴 휴리스틱, 검증이 없으므로 마지막 가중치 사용).
- **제출 후보 3종 생성**: 11s+11m 앙상블(주력) · 11s 단일 · 11m 단일. 테스트 842장 모두 예측, 이미지당 확신 박스 3.6~3.7개(학습 데이터 3~4개와 일치).
- 최종 모델 폴더에 Ultralytics가 그린 PR 곡선·혼동 행렬은 **학습에 포함된 이미지로 계산된 것**이라 지웠다. 성능처럼 보이면 오해를 부른다.

## 고민 / 결정
- 자동화한 규칙의 결과는 반드시 눈으로 검수한다. 라벨 수정 규칙의 오탐 5건을 잡아낸 것처럼, 자동 처리 결과를 의심하고 검증하는 과정을 반드시 거친다.
- 학습 환경은 처음에 Kaggle 노트북으로 정했지만, 실험 20여 개를 빠르게 반복하려고 **로컬 GPU(RTX 3060)로 바꿨다** (Kaggle은 주간 GPU 시간 한도가 있다). 노트북은 결과 분석·시각화용으로 쓴다.
- GPU 하나에 학습 두 개를 동시에 돌리면 오히려 크게 느려졌다 → 학습은 대기열로 하나씩 순서대로 돌린다.
- 검증 점수는 **분할 구조**에 크게 좌우된다. 숫자 하나를 보기 전에 "이 숫자의 상한이 얼마인가"부터 계산한다.

## 3. 기술 설계

### 3.1 전체 구조
```
[이미지] → ① 검출기 (YOLO) ─ 위치 + 1차 클래스
              │
              └→ 박스 crop → ② 분류기 (ResNet / EfficientNet / VGG) ─ 약 종류 재판정
                                │
                                └→ ③ 결합 · 후처리 (이미지당 최대 4개, NMS/WBF) → 제출
```
- **왜 2단계인가**: 클래스 56종에 비해 학습 박스가 771개뿐이고 29종은 10개 미만이다. 검출기는 "알약이 어디 있는가"만 잘 하면 되고(사실상 1클래스 문제라 데이터가 충분하다), 종류 판별은 crop 단위 분류기가 맡는다. 분류기는 crop마다 강한 증강을 줄 수 있어 희귀 클래스에 유리하다.
- 단일 YOLO(56클래스)를 베이스라인으로 두고, 2단계 구조가 실제로 나은지 **같은 fold에서 비교해 결정**한다.

### 3.2 모델 후보
| 역할 | 후보 | 비교 목적 |
|:---|:---|:---|
| 검출기 | YOLO (Ultralytics) n / s / m 크기 | 모델 크기 대비 성능, 학습 시간 |
| 검출기 (대조군) | Faster R-CNN (torchvision) | 1단계(YOLO) vs 2단계 검출기 구조 비교 |
| 분류기 | VGG16, ResNet50, EfficientNet-B0 (+ ConvNeXt-T) | 가이드의 CNN 모델 비교, 정확도·정밀도·재현율·F1 |

### 3.3 평가 지표
| 단계 | 지표 | 이유 |
|:---|:---|:---|
| 검출 전체 | **mAP@50-95**, mAP@50 (대회 지표에 맞춰 주 지표 확정) | 위치 정확도와 분류를 함께 평가 |
| 분류기 | Accuracy, Macro Precision / Recall / F1, 혼동 행렬 | 불균형 데이터라 Macro 평균으로 희귀 클래스까지 반영 |
| 분석 | 클래스별 AP, 실패 사례 | 어떤 약이 왜 틀리는지 → 다음 실험 근거 |

### 3.4 도메인 지식 활용
- **이미지당 알약은 최대 4개** → 예측을 신뢰도 상위 4개로 제한 (`max_det=4`). 오탐을 줄인다.
- **같은 이미지에 같은 약은 한 번만 나온다** (EDA 확인) → 클래스 중복 예측을 정리한다.
- **알약은 위에서 찍어 방향이 자유롭다** → 상하·좌우 뒤집기와 90° 회전 증강을 써도 라벨이 깨지지 않는다.

## 4. 실험 설계
**원칙: 한 번에 한 가지만 바꾼다.** 빠른 비교는 fold 0, 최종 후보는 5-Fold로 확인한다. seed는 42로 고정한다.

| 단계 | 실험 | 가설 | 비교 |
|:---:|:---|:---|:---|
| E0 | 베이스라인: YOLO-s, 640px, 기본 증강 | 기준점 | – |
| E1 | 입력 해상도 640 → 960 → 1280 | 각인 같은 세부 특징이 중요하므로 해상도가 클수록 좋다 | E0 |
| E2 | 모델 크기 n / s / m | 데이터가 적어 큰 모델은 과적합될 수 있다 | E0 |
| E3 | 증강: 회전·뒤집기, HSV, Copy-Paste | 희귀 클래스와 위치 편향 문제를 완화한다 | 최적 E1·E2 |
| E4 | 이미지 전처리: CLAHE, 색 정규화 | Train/Test 밝기 차이를 줄인다 | E3 |
| E5 | 하이퍼파라미터: 학습률, 배치, 에포크, optimizer | 수렴 안정화 | E3 |
| E6 | 2단계: 검출기 + 분류기 (VGG / ResNet / EfficientNet) | 희귀 클래스 분류가 개선된다 | E5 |
| E7 | 검출기 대조군: Faster R-CNN | 구조 차이 확인 | E5 |
| E8 | 추론: TTA, `max_det=4`, conf 임계값 | 도메인 지식으로 오탐을 줄인다 | 최적 모델 |
| E9 | 5-Fold 앙상블 (WBF) | 분산 감소 | E8 |
| E10 | 테스트 의사 라벨링 (고신뢰 예측만) | 842장의 추가 데이터 효과 | E9 |
